# pairwise-virtual-texture

角色跑向山脊，远处地表先糊成一块灰，停下来才一页页变清楚，转头又整片闪回低清：虚拟纹理的页表按固定 mip 常驻，相机距离变化时没有重算页优先级；反馈缓冲只统计屏幕像素，斜视角和远景页被漏掉；页请求在帧末统一提交，快速转身时低清页先显示；异步上传和采样共用一张页表，未完成页读到旧内容；纹理压缩块跨页边界，页边缘出现色带；多相机分屏各自请求同一页，缓存被互相驱逐；各向异性过滤没把页尺寸算进去，远处纹理被过度模糊；地形 LOD 切换时 UV 偏移没更新，页表错位；显存预算按页数而不是字节，压缩格式切换后爆显存；页淘汰按最近使用时间，过场动画相机一扫把常用页清掉；跨页采样没有 border 数据，接缝漏底色；流送优先级只看距离，角色脚下的页反而最后到；GPU 页表和 CPU 副本异步更新，采样到未映射页返回黑块。render/virtual_texture.py 是核心，tests/test_virtual_texture.py 15个红。要修的是：页优先级；反馈覆盖；请求时机；异步完成；压缩边界；多相机共享；各向异性页尺寸；LOD UV；字节预算；淘汰保护；border 采样；脚下优先；页表同步。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
